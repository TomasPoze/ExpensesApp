## Overview

ExpensesApp is a versatile, cross-platform expense management application built with .NET MAUI, enabling users to track, categorize, and visualize their financial data seamlessly across devices. Its modular architecture combines core models, services, repositories, and API layers to deliver a scalable and maintainable solution.

**Why ExpensesApp?**

This project helps developers create robust financial apps with ease. The core features include:

- 📊 **Visual Data Insights:** Rich pie and column charts for intuitive expense analysis.
- 🔌 **API Integration:** Secure RESTful endpoints for CRUD operations and real-time data sync.
- 📱 **Cross-Platform Compatibility:** Supports Android, iOS, Windows, macOS, and Tizen with platform-specific configurations.
- 🧩 **Modular MVVM Architecture:** Dependency injection, validation, and navigation for maintainable code.
- 🎨 **Custom UI Components:** Reusable views, drawable charts, and styling resources for a cohesive user experience.
- 🚀 **Scalable & Extensible:** Designed for growth with clear separation of concerns and platform adaptability.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** CSharp
- **Package Manager:** Nuget

### Installation

Build ExpensesApp from the source and install dependencies:

1. **Clone the repository:**

```sh
git clone https://github.com/TomasPoze/ExpensesApp
```

2. **Navigate to the project directory:**

```sh
cd ExpensesApp
```

3. **Install the dependencies:**

Using nuget:
```sh
dotnet restore
```

### Usage

Run the project with:

Using nuget:
```sh
dotnet run
```

### Testing

ExpensesApp uses the xUnit test framework. Run the test suite with:

Using nuget:
```sh
dotnet test
```
